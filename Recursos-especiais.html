Para trocar o fundo de um elemento, utilize o comando background-color

Comando completo de alterar cor de fundo:

            code{
                color: red;
                background-color: aliceblue;
            }
Como troco a cor de fundo de um elemento no HTML?

Para realizar essa ação, utilize a propriedade background-color no CSS.
