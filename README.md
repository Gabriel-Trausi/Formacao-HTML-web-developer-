# HTML Web Developer Básico

Repositório com exercícios e exemplos desenvolvidos durante os estudos de **HTML Web Developer Básico**, curso realizado na [DIO.me](https://www.dio.me/).

O conteúdo reúne práticas introdutórias de estruturação de páginas, textos, links, listas, tabelas, formulários, elementos semânticos e alguns recursos de CSS e JavaScript usados nos exemplos.

## Arquivos e aprendizados

- **[Index.HTML](./Index.HTML)** — primeiros elementos HTML: estrutura básica da página, títulos e campos de entrada de texto, número, senha e cor, além de um botão.
- **[Text.html](./Text.html)** — títulos e parágrafos, com exemplos de texto em destaque (`strong` e `mark`), citação (`blockquote`) e sublinhado (`u`).
- **[Formatação_de_texto.html](./Formatação_de_texto.html)** — elementos para diferentes formatos e significados de texto, como itálico, negrito, subscrito, sobrescrito, código, abreviações, citações e datas.
- **[Listas.html](./Listas.html)** — criação de listas ordenadas e não ordenadas, com uma lista ordenada aninhada.
- **[links.html](./links.html)** — links internos entre páginas do projeto e link externo para a DIO.me, incluindo atributos como `title` e `target`.
- **[Div_e_spans.html](./Div_e_spans.html)** — agrupamento de conteúdo com `div` e uso de `span` dentro de links; exemplo de organização de uma lista de navegação.
- **[Cores.html](./Cores.html)** — aplicação de cores em CSS com valores hexadecimal e RGBA, transparência, dimensões, posicionamento e sobreposição de elementos.
- **[Tabelas.html](./Tabelas.html)** — estrutura de tabelas com título, cabeçalho, corpo e rodapé, além de células de dados e estilos CSS para cores, bordas, sombra e interação ao passar o mouse.
- **[Semantica.html](./Semantica.html)** — exemplos de elementos semânticos (`header`, `nav`, `main`, `section`, `article`, `aside` e `footer`), navegação por âncoras e link de e-mail.
- **[main-header-footer.html](./main-header-footer.html)** — estrutura inicial de uma página usando as áreas semânticas `header`, `main` e `footer`.
- **[Form.html](./Form.html)** — formulário básico de cadastro com campos de nome, idade, e-mail e senha, além de controles para envio.
- **[Input.html](./Input.html)** — demonstração de vários tipos de `input`, como texto, número, intervalo, cor, e-mail, URL, data, arquivo, busca, seleção, senha e telefone; inclui `datalist` e botões de envio e limpeza.
- **[Select.html](./Select.html)** — formulário com campos de texto, área de mensagem (`textarea`), botão de envio e lista de opções criada com `select` e `option`.
- **[Fieldsets.html](./Fieldsets.html)** — agrupamento de campos de formulário com `fieldset` e `legend`, incluindo dados pessoais, endereço, seleção de estado e informações de contato; também aplica estilos CSS.
- **[Check_box_e_radio.html](./Check_box_e_radio.html)** — uso de caixas de seleção (`checkbox`) para múltiplas escolhas e botões de opção (`radio`) para escolhas únicas em um exemplo de pedido de pizza.
- **[Button.html](./Button.html)** — tipos de botão para ações, envio e limpeza de formulário, estado desabilitado e eventos simples de clique e passagem do mouse.
- **[Iframe.html](./Iframe.html)** — exemplo de inclusão de conteúdo remoto usando uma imagem com endereço da DIO.me. Apesar do nome do arquivo, o exemplo atual não contém um elemento `iframe`.
- **[Recursos-especiais.html](./Recursos-especiais.html)** — recursos HTML como `datalist`, `select`, `details`/`summary`, `meter` e `progress`, além de `kbd`, `code` e `pre`; inclui exemplos de JavaScript para atualizar uma barra de progresso e destacar termos pesquisados com `mark`.

## Como visualizar

Abra o arquivo **[Index.HTML](./Index.HTML)** ou qualquer outro arquivo `.html` diretamente em um navegador. Cada página é um exercício independente.

## Tecnologias praticadas

- HTML para estruturar e organizar o conteúdo.
- CSS básico para cores, dimensões, posicionamento e apresentação.
- JavaScript introdutório em exemplos de interação na página.
